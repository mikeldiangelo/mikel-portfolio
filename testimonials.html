Student Management System

A full-stack web system for managing student records with admin authentication

--Challange

Managing student registrations manually through spreadsheets or paper records creates room for errors, data loss and slow retrieval. There was a need for a centralized system where an admin could register, track, update and delete student records efficiently with a proper access control layer.

--Execution

Built a full-stack student management system using PHP and MySQL with OOP principles. The system includes secure admin registration and login with hashed passwords, protected session management, student registration with image upload and input validation, a searchable student table with pagination, edit and delete functionality, a JOIN query linking students to the admin that registered them, an admin dashboard showing total students and a registration log file written to storage on every new entry.

--Result

A fully working system that allows authenticated admins to manage student records end to end. Data is stored persistently in a MySQL database, all actions are validated and sanitized to prevent errors, and every registration is automatically logged with a timestamp for record keeping.

Brand Identity & Content

Personal brand setup and content strategy for a freelance digital services page

--Challange

The page had no clear visual identity or positioning. The bio wasn't communicating what the page offered or who it was for, making it difficult for visitors to understand the value quickly enough to follow or reach out. There was no cover photo, no structured messaging and no content direction.

--Execution

Designed a professional cover photo using Canva that clearly states the name, niche and call to action. Wrote a structured bio using a three line format that communicates the value proposition, the method and a follow prompt. Set up the page category, location and school details to improve discoverability. Crafted the page headline to include a role descriptor as a trust signal alongside the name.

--Result

The page now has a clear, professional first impression that communicates the offer within seconds of landing on it. The cover photo doubles as a silent pitch, the bio qualifies the right audience and the overall profile is set up to convert profile visitors into followers and potential clients.

Key Achievement

Transformed a blank, unpositioned page into a structured personal brand that clearly communicates web design and digital marketing services, supported by a cover photo CTA directing visitors to send an inbox message to collaborate.
